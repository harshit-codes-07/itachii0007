- 👁️ **60FPS Live Canvas Wallpaper**:
  - Tsukuyomi Crimson Blood Moon with atmospheric glow and tomoe silhouette.
  - Procedurally animated flock of flying crows / ravens with wing-flapping physics.
  - Floating chakra embers responsive to cursor / touch movement.
  - Interactive click shockwave distortion ripples.
- 🎵 **Web Audio Synthesizer**:
  - In-browser atmospheric shinobi wind and meditative drone soundscape generated with pure Web Audio API (zero external audio dependencies).
- 📜 **Shinobi Arsenal (Skills)**:
  - Highlights Python (Core logic & Automation), Web Development (HTML5, CSS3, Modern JS), Git/GitHub, and Calisthenics discipline.
- 💻 **Interactive Jutsu Terminal**:
  - Terminal emulator supporting commands like `help`, `skills`, `projects`, `mangekyo`, `tsukuyomi`, `itachi`, and `quote`.
- 📊 **Live GitHub Integration**:
  - Fetches and displays real-time profile data and repository stats directly from the GitHub API.
- 📱 **Mobile & Desktop Responsive**:
  - Fully adaptive layouts, custom scrollbar, and glassmorphic UI panels.
